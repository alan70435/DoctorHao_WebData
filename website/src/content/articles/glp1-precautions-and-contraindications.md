系列第二篇，整理程皓醫師關於**禁忌、注意事項與安全使用**的說明。

## 什麼情況不能打？

其實多數情況都能打，極少數不行。程皓醫師的整理：

| 狀況 | 可否 |
|---|---|
| 甲狀腺結節 | 可以打，建議追蹤 |
| 甲狀腺亢進或低下 | 可以打，需與醫師討論（功能問題治療好、諮詢後可考慮） |
| 月經中 | 可以打，不影響 |
| 青少年 12–18 歲 | 可以打週纖達、胰妥讚，需與醫師討論 |
| 肥胖、糖尿病、多囊性卵巢 | 更需要打 |
| 服用口服避孕藥（雌激素類） | 需注意，可能影響吸收，需討論 |
| BMI 20 以下 | 不太建議，需要討論 |
| 甲狀腺髓樣癌、MEN2 | **不能打** |
| 備孕、懷孕、哺乳 | **不能打** |
| 嚴重肝腎功能問題 | **不能打** |

其他常見疑問：與施打流感疫苗不衝突；出國前後若需施打，平移兩天內不影響。

## 為什麼要抽血？

抽血在有定期檢查的健康成人確實非必要，但程皓醫師認為至少要了解近期數據：

1. 了解基本肝腎功能，是使用前最基本的須知。
2. 了解有無脂肪肝造成的肝功能異常——有異常更須積極減重。
3. 了解使用前後的血糖、膽固醇變化，可找到隱性的高血糖、高膽固醇，同時治療。
4. 長期肥胖問題需排除甲狀腺功能問題。

## 噁心嘔吐，大多是劑量調控的問題

打瘦瘦針若出現明顯反胃、噁心嘔吐，大概率是劑量調控出現問題，很可能是**自己私下調劑**造成。若從胰妥讚作為初期使用、後續再轉換至猛健樂，反應大多很好。建議在醫師監督下追蹤施打，較有機會達到最佳效果。

## 最嚴重的副作用，都與吃太少、喝太少有關

- **脫水** → 胰臟炎、缺血性視神經病變等。
- **熱量過低** → 落髮、月經不來等。

因此絕對不要提倡完全吃不下、喝不下。副作用少、胃口能適當抑制三到五成，搭配飲食控制及運動，就是最佳效果。

## 單次施打，看似省錢卻充滿風險

1. 與其他人共用針劑，若施打過程出現回血，可能傳染血液相關疾病（B 肝、愛滋等）。
2. 有不肖診所以胰妥讚或其他藥物冒充猛健樂施打——你可能無從確認自己打了什麼。
3. 施打大多非標準劑量，而是以最高濃度打較低劑量的方式，效果較未知。
4. 每週跑診所很累；帶回家每週施打很方便。

這些才是最可怕的，而非噁心嘔吐等初期副作用。請為自己的健康負責。

## 怕打針？針頭細到不可思議

很多朋友猶豫的理由是怕打針。其實它與抽血用的 18 號針完全不一樣：用的是 32 號針（號碼越大越細），跟胰島素的針一樣細。打在肚皮上比蚊子叮還無感——程皓醫師自己也很怕抽血，但這個真的無感。

## 會掉肌肉嗎？

所有減重都會掉肌肉，猛健樂也不例外。脂肪與肌肉流失的比例大約 3：1，是合理的比例；**增加蛋白質攝取與肌力訓練**可以幫助保留肌肉。

## 重點整理

- 絕對禁忌：備孕懷孕哺乳、甲狀腺髓樣癌／MEN2、嚴重肝腎功能問題。
- 需討論：甲狀腺疾病、青少年、口服避孕藥、BMI 20 以下。
- 治療前了解肝腎功能、血糖血脂、脂肪肝與甲狀腺。
- 噁心嘔吐多為劑量問題；別自行加量；維持水分與基本熱量。
- 不共用針劑、不打來源不明的藥。
